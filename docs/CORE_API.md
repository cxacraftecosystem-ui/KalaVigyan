# Shared code catalogue

Every shared backend component, with what it guarantees. Check here before writing a helper; if
what you need is close to something listed, extend it. A component enters this list when a
second real caller exists, and leaves it in the same change that deletes it. Paths are under
`backend/app/`.

| For | Read |

## core/db.py: database sessions

| Name | Guarantee |
|---|---|
| `build_runtime_database_url(base_url) -> RuntimeDatabase` | Converts a Postgres URL to `postgresql+psycopg`, drops Prisma-only parameters, and records the connect arguments and whether it is the Supabase transaction pooler (`TRANSACTION_POOLER_PORT`) or the session pooler (`SESSION_POOLER_PORT`). |
| `get_engine()`, `sessionmaker()` | One async engine and session factory per process. The engine hides statement parameters from its errors and logs (`hide_parameters`, decision 0150). Its pool is the process's budget (`process_pools(settings).main`, decision 0163): a few connections kept, the rest opened for a burst and closed when returned. |
| `process_pools(settings) -> ProcessBudget`, `counting_sessionmaker()`, `dispose_counting_engine()`, `COUNTING_WAIT_SECONDS` | The process's connection budget (decision 0163): `KV_PROCESS` names it (`core/connection_budget.BUDGETS`); on the box a process that names none is a script; off the box (tests, a laptop) an unnamed process keeps `DATABASE_CONNECTION_LIMIT` and `DATABASE_MAX_OVERFLOW`. The one counting engine of the process, sized by the budget's counting pool with a 5 s wait, serves `core/allowances` and `core/paces`; `dispose_engine()` closes it too. |
| `core/connection_budget`: `BUDGETS`, `PoolBudget(kept, burst)`, `ProcessBudget(main, counting)`, `process_role(named, *, production)`, `peak_sessions(instances)`, `most_runs(pool)`, `POOLER_SESSIONS`, `POOLER_HEADROOM`, `BLUE_GREEN_SLOTS`, `RUN_CONNECTIONS` | Every process on the box against the Supabase session pooler's 45 sessions: the API (10 and 2 counting, two slots during a deploy), the contribution queue (8 and 1), the worker (2 and 1) and one script (3 and 1) sum to 40, leaving 5; the fetcher has no database. `backend/tests/test_connection_budget.py` sums the units in `infra/deploy/units` and fails when a process or a limit would pass the pooler. |
| `core/pooler`: `connected_session(sessions, *, waits, sleep)`, `pooler_full(error)`, `POOLER_RETRY_WAITS` | A session whose connect the pooler refused for want of room (`EMAXCONNSESSION`) is opened again after 0.2, 0.5 and 1 s; any other failure, or the last refusal, is raised, so a guard over it still fails closed. |
| `research_sessionmaker()` | The session factory answers research through (decision 0146): the same engine, but every session holds a slot of one `core/research_gate.ResearchGate` sized `research_slots(pool_size, max_overflow)`, so research never takes the last `SHORT_REQUEST_CONNECTIONS` (2) connections a sign-in or page read needs; a session opened while its task already holds a slot takes no second one. |
| `get_session()` | FastAPI dependency yielding one `AsyncSession` per request. |
| `session_scope()` | Async context manager: commits on success, rolls back on any error. |
| `ping()`, `dispose_engine()` | Readiness probe (raises when the database does not answer) and shutdown. |

|---|---|

| `Bucket(holder, kind, start, seconds)`, `bucket_of(holder, kind, now, *, seconds)`, `SharedCounter(sessions=None, *, seconds, waits)`, `delete_old_buckets(session, *, now)`, `AllowanceUnread`, `ALLOWANCE_UNREAD` | Windows counted from 1970-01-01 UTC; counted through the process's counting engine (`core/db.counting_sessionmaker`, its size the process's budget, decision 0163) within 5 s, a connect the pooler refused tried again through `core/pooler.connected_session`; buckets older than 24 hours deleted by the nightly upkeep; a count that cannot be read is `AllowanceUnread`, and the caller refuses. |---|---|
